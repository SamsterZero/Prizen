# AI-Assisted Development

AI may accelerate documentation, scaffolding, test authoring, code review, and issue preparation. A maintainer remains accountable for architectural decisions, marketplace terms compliance, secrets, migrations, and every production change.

Before implementation, update the affected specification and identify module ownership. Before merging, run formatting, linting, type checks, and relevant tests. AI-generated marketplace adapters require manual review against the marketplace's applicable access policy and must not bypass access controls.

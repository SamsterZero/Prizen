# UI/UX Specification

Prizen should feel calm, decisive, and trustworthy: a focused finance-like tool rather than a bargain-hunting feed.

## Visual language

- Indigo is the primary action and data color; emerald communicates savings or successful drops; amber represents pending work.
- Surfaces are soft off-white with white cards, restrained shadows, and generous rounded corners.
- Display typography is bold and compact; explanatory copy is relaxed and readable.
- Price changes use both text and directional symbols—colour is never the only signal.

## Core views

The dashboard shows a compact tracking list, while each product's tracking-details page owns its price-history chart and 24-hour, 7-day, 30-day, and 90-day range selector. Settings use separate Marketplace, Delivery, and Notification destinations with persistent active navigation. The public About and Privacy pages explain the product and its local data boundary without requiring database access.

## Accessibility

All controls need visible focus states, semantic labels, keyboard access, and sufficient contrast. Dialogs must be dismissible with Escape and restore focus to the invoking control when closed. Charts receive an equivalent text summary.
